# Soccer Fitness Tracker - App Store Pages

Public website for Soccer Fitness Tracker iOS app containing:
- Privacy Policy
- Support Page
- Marketing Landing Page
- App screenshots (sourced from `fastlane/screenshots` in the iOS repo)

## URLs (after enabling GitHub Pages)

- **Home**: https://umang-desai.github.io/soccer-fitness-tracker-site/
- **Privacy Policy**: https://umang-desai.github.io/soccer-fitness-tracker-site/privacy.html
- **Support**: https://umang-desai.github.io/soccer-fitness-tracker-site/support.html
- **App Store**: https://apps.apple.com/us/app/soccer-fitness-tracker/id6756504677

## Setup GitHub Pages

1. Go to repository **Settings**
2. Click **Pages** in the sidebar
3. Under "Source", select **Deploy from a branch**
4. Select **develop** branch and **/docs** folder
5. Click **Save**

Your site will be live in a few minutes!

## Local preview

From the repo root:

`python3 -m http.server 8000 --directory docs`

Then open `http://localhost:8000`.
