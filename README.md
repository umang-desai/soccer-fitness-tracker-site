## Setup GitHub Pages

1. Go to repository **Settings**
2. Click **Pages** in the sidebar
3. Under "Source", select **Deploy from a branch**
4. Select **develop** branch and **/ (root)** folder
5. Click **Save**

Your site will be live in a few minutes!
